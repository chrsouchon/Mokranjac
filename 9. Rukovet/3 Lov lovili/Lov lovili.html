3 Lov lovili građani

Messieurs les chasseurs

(Deveta Rukovet - 9ème guirlande :01:58,5 - 02:28 )


 



ВЕРЗИЈА ДЕВЕТЕ РУКОВЕТИ

Лов ловили грађани,
Бисер-роса, магла пала,
грађани, грађани ...





TRADUCTION  

Ces messieurs partaient pour la chasse,
La rosée perlait, le brouillard planait,
Ces messieurs, ces messieurs...






Version Mokranjac
